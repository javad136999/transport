# سامانه مدیریت و نظارت بر حمل پساب

مالک و مدیر سامانه: **شرکت پیمانکاران تصفیه صنعت**

زنجیره دیجیتال رهگیری حمل پساب صنعتی/بهداشتی پتروشیمی‌های منطقه ویژه اقتصادی انرژی پارس: از درخواست حمل تا بارگیری، جابه‌جایی با GPS، تخلیه در مقصد مجاز، تأیید مقصد و آرشیو مستندات.

## این پروژه چیست و چه چیزی هنوز باقی مانده

این ریپازیتوری یک **پایه واقعی و قابل‌توسعه** است، نه یک Demo:

- **اسکیمای کامل دیتابیس** (۳۵+ جدول، طبق بخش ۷۳ سند) با تمام Foreign Keyها، enum های وضعیت، و تابع Normalize پلاک — در `supabase/migrations/0001_schema.sql`
- **سیاست‌های امنیتی RLS واقعی** برای چندمستاجری کامل (هر پتروشیمی فقط داده خودش را می‌بیند، Super Admin به همه دسترسی دارد، ناظران Read-Only هستند) — در `supabase/migrations/0002_rls.sql`
- **Bucketهای Storage خصوصی** برای مدارک/عکس‌ها — در `supabase/migrations/0003_storage.sql`
- **صفحات کاملاً کارکردی متصل به Supabase**: ورود (رمز عبور یا OTP موبایل)، داشبورد مدیر سامانه با KPI زنده، فرم ایجاد مأموریت پتروشیمی (با قاعده «فقط راننده/تانکر تأییدشده همان پتروشیمی»)، اپ موبایل راننده (دکمه‌های مرحله‌به‌مرحله + ثبت GPS + صف Offline)، استعلام دستی پلاک برای مأمور گشت
- **میان‌افزار احراز هویت** (`middleware.ts`) که کاربر را بر اساس نقش به داشبورد درست هدایت می‌کند

**آنچه باید قبل از ارائه به مشتری واقعی تکمیل شود:**
سایر صفحات لیست‌شده در منوها (مدیریت رانندگان/تانکرها، پرداخت و پیش‌فاکتور، گزارش‌ساز Excel/PDF، نقشه زنده با MapLibre، مرکز هشدار و Risk Score، ثبت‌نام پتروشیمی و تأیید مدیر، صفحه تنظیمات) — همان الگوی صفحات موجود (Server/Client Component + Supabase query + RLS) را دنبال می‌کنند و می‌توان آن‌ها را به همین شکل افزود. من نمی‌توانم یک پروژه واقعی Supabase/Vercel برای شما بسازم یا دیپلوی کنم؛ این کار باید با حساب‌های خودتان انجام شود (مراحل زیر).

## استقرار گام‌به‌گام

### ۱. ساخت پروژه Supabase
۱. به [supabase.com](https://supabase.com) بروید و پروژه جدید بسازید.
۲. در **SQL Editor**، فایل‌های زیر را **به همین ترتیب** اجرا کنید:
   - `supabase/migrations/0001_schema.sql`
   - `supabase/migrations/0002_rls.sql`
   - `supabase/migrations/0003_storage.sql`
   - (اختیاری برای تست) `supabase/seed/seed.sql`
۳. از **Authentication → Providers**، ورود با Email/Password و Phone/OTP (نیازمند تنظیم یک ارائه‌دهنده پیامک مثل Twilio/Kavenegar) را فعال کنید.
۴. از **Project Settings → API**، مقادیر `URL` و `anon key` و `service_role key` را بردارید.

### ۲. راه‌اندازی محلی
```bash
npm install
cp .env.example .env.local   # مقادیر Supabase را جایگزین کنید
npm run dev
```

### ۳. ساخت اولین کاربر Super Admin
پس از ثبت‌نام یک کاربر از صفحه ورود (یا از Supabase Studio → Authentication)، در جدول `users` یک ردیف بسازید که `id` آن برابر `auth.users.id` و `role = 'super_admin'` باشد:
```sql
insert into users (id, full_name, role)
values ('<AUTH_USER_UUID>', 'مدیر سامانه', 'super_admin');
```

### ۴. انتشار روی GitHub
```bash
git init
git add .
git commit -m "راه‌اندازی اولیه سامانه مدیریت حمل پساب"
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```

### ۵. دیپلوی روی Vercel
۱. ریپازیتوری GitHub را در [vercel.com](https://vercel.com) Import کنید.
۲. سه متغیر محیطی `.env.example` را در **Project Settings → Environment Variables** وارد کنید.
۳. Deploy را بزنید — Framework Preset به‌صورت خودکار Next.js تشخیص داده می‌شود.

## اصول طراحی رعایت‌شده
- **چندمستاجری با RLS واقعی**: هیچ فیلتر تنانت در کد Frontend انجام نمی‌شود؛ همه در سطح دیتابیس با Postgres RLS اعمال می‌شود، طبق بند ۳ سند.
- **مأموریت فقط توسط پتروشیمی ایجاد می‌شود** و فقط راننده/تانکر دارای تأیید معتبر همان پتروشیمی (جداول `driver_approvals`/`vehicle_approvals`) قابل انتخاب هستند (بند ۱۱، ۱۳، ۱۸).
- **GPS قطع = توقف مأموریت نیست**: وضعیت GPS Lost ثبت و آخرین موقعیت معتبر نگهداری می‌شود (بند ۲۲، ۲۶، ۶۶).
- **هیچ هشدار/وضعیت مشکوکی به‌معنی تخلف قانونی قطعی نیست** — این اصل در کامنت‌های کد و در UI (وضعیت «نیازمند بررسی») رعایت شده (بند ۶۷).
- **حریم خصوصی راننده برای مأمور گشت**: نام کامل و کد ملی راننده در صفحه استعلام نمایش داده نمی‌شود (بند ۵۰).
- **پلاک فارسی/انگلیسی Normalize می‌شود** (`normalizePlate` در `src/lib/utils.ts` و تابع معادل SQL) — بند ۷۵.

## هزینه‌های جاری (تخمینی)
- Supabase: پلن رایگان برای توسعه؛ برای Production با چند پتروشیمی و ترافیک GPS مداوم، پلن Pro ($25/ماه به بالا) توصیه می‌شود.
- Vercel: پلن رایگان برای شروع کافی است؛ برای دامنه اختصاصی و ترافیک بالاتر پلن Pro.
- سرویس پیامک OTP (در صورت استفاده از ورود با موبایل): هزینه جداگانه بر اساس ارائه‌دهنده.
